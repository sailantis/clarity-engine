Filter Examples

Filters transform data before output using the |> operator.

Text Filters

Original: {{ text }}
Upper: {{ text |> upper }}
Lower: {{ text |> lower }}
Capitalize: {{ text |> capitalize }}
Title: {{ text |> title }}
Trim: "{{ messyText |> trim }}"
Truncate: {{ longText |> truncate(50) }}

Number Filters

Original: {{ price }}
Number (2 decimals): {{ price |> number(2) }}
Number (0 decimals): {{ price |> number(0) }}
Rounded: {{ price |> round(1) }}
Absolute value: {{ negativeNumber |> abs }}

Type Casts

A cast converts a value's type. Use it when a value arrives as a string (a form field, a database column, a decoded payload) and the numeric filters need a number.

Int (truncates): {{ priceString |> int }}
Float (keeps the fraction): {{ priceString |> float }}
String: {{ price |> string |> trim }}
Bool (PHP truthiness, not emptiness): {{ zeroString |> bool }}
Array (wraps a scalar): {{ price |> array |> json |> raw }}
Object (wraps a scalar; pipe it into a serializer): {{ price |> object |> json |> raw }}
Cast, then a numeric filter: {{ priceString |> float |> round(2) }}
PHP cast syntax: {{ (int) priceString }} and {{ abs((int) negativeString) }}

Date Filters

Default format: {{ timestamp |> date }}
Custom format (d.m.Y): {{ timestamp |> date('d.m.Y') }}
With time (H:i:s): {{ timestamp |> date('Y-m-d H:i:s') }}
Readable format: {{ timestamp |> date('F j, Y') }}

Filter Chaining

Multiple filters can be chained together:

Chain: {{ text |> lower |> trim |> capitalize }}
Complex chain: {{ description |> trim |> truncate(100) |> upper }}

Lambda Filters

Use lambdas with map, filter, and reduce:

Map (extract names): {{ users |> map(u => u:name) |> join(', ') }}
Filter (active only): {{ users |> filter(u => u:active) |> map(u => u:name) |> join(', ') }}
Map with filter (uppercase): {{ tags |> map(t => t |> upper) |> join(' | ') }}
